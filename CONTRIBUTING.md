# Contributing

Issues and pull requests are welcome for client improvements, examples, documentation, and reproducible bugs.

1. Open an issue to discuss substantial changes.
2. Keep pull requests focused and include tests where applicable.
3. Run `npm run check` before submitting.
4. Never commit secrets or user wallet data.

Token registration and metadata updates take place at [WIND Assets](https://assets.windcrypto.com/), not through pull requests. This repository does not store or approve token listings.
